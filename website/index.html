The Agent Keeps Going.

Lidless keeps your Mac awake with the lid closed for exactly as long as your coding agent is working. No timer to guess, no external monitor, no Terminal commands. When the agent finishes, the Mac goes back to sleep.

What it does

Every keep-awake app asks the same question: for how long? 30 minutes, 2 hours, forever. The honest answer is "until Claude is done", and no timer knows when that is. Too short and the run dies halfway through a refactor. Too long and the Mac burns battery all night for nothing.

Lidless watches the agent instead of the clock. While an agent is working it holds Apple's own pmset disablesleep, the one setting that covers lid-close sleep. The moment the work stops, it lets go. There is no duration setting. That's the point.

Why it exists

Cloud agents keep running when the laptop shuts. Local agents die the second the lid closes.

Long agent runs are the new compile step. Start a task, grab the laptop, walk to the next meeting, and macOS puts the whole session to sleep before the hallway ends. People carry MacBooks around half-open to stop it. Paying for a cloud sandbox just to keep a process alive is overkill when the machine on the desk already has the repo, the keys and the toolchain.

Lidless gives local agents the one thing cloud agents have: they keep working when nobody is watching. Closing the lid to sleep the Mac still works the rest of the time.

How it knows

Claude Code: exact

Lidless adds three hooks to ~/.claude/settings.json. UserPromptSubmit starts a hold, Stop and SessionEnd end it. Accurate to the second, across every session and every terminal.

Other agents: by activity

Everything else is detected by process. An agent counts as working while it or anything it spawned is using CPU. Lidless waits two quiet minutes before letting go, so a slow model response is not mistaken for done.

Anything else: wrap it

Long build, test suite, training run, a script that babysits an agent. Put lidless run in front and the Mac stays awake until it exits.

$ lidless run -- npm run e2e
$ lidless run -- ./agent-loop.sh --overnight
$ lidless status

Install

  1. Download Lidless.zip from GitHub Releases and drag Lidless to Applications.

  2. Open it and click Set Up. macOS asks for your password once.

  3. Start an agent. Close the lid.

What Set Up changes, exactly. It adds /etc/sudoers.d/lidless, which lets your user run two commands without a password: pmset -a disablesleep 1 and pmset -a disablesleep 0. Nothing else. It also links the lidless command into /usr/local/bin. The Claude Code hooks are added in the background whenever Claude Code is installed, with a backup of your settings kept first. Uninstall… in the menu removes all of it.
Not on the App Store because App Store sandboxing blocks the system call lid-close sleep needs. Same reason tools like Lunar and BetterTouchTool ship outside it.

Safety

Use this tool AT YOUR OWN RISK. The command Lidless runs is Apple's own, and it only runs while an agent is actually working. No guarantees beyond that.

Two rules: keep the Mac on a hard surface while an agent runs, and never put it in a bag mid-run. A closed laptop in a bag with sleep disabled will overheat.

Lidless lets go on its own when the battery drops to 20% on battery power, when macOS reports a critical thermal state, or when the app quits. Plug in for long runs.

FAQ

Can a timer be set?

No. The agent decides. When it is working the Mac is awake, when it is done the Mac can sleep. Anything that isn't an agent can be wrapped with lidless run.

Does it work without an external monitor?

Yes. That is the whole job. Most keep-awake apps hold display or idle sleep, which closing the lid ignores. pmset disablesleep is the switch for lid-close sleep itself.

What happens when the agent finishes with the lid closed?

Lidless restores normal sleep and puts the Mac to sleep within a few seconds, unless an external display is attached. Open the lid later and the finished work is waiting.

What if Claude Code is waiting on a permission prompt?

A permission prompt is not a finished turn, so the Mac stays awake waiting for an answer. For unattended runs, use auto mode or allow rules so nothing blocks. If a session goes fully quiet for 15 minutes without finishing, Lidless lets it go anyway.

Does Cloud Mode need to be turned on every time?

No. Leave it on. With no agent working, Lidless does nothing and the Mac sleeps like normal. Turn it off from the menubar to ignore agents entirely.

Does it drain battery faster?

Only while an agent is working, and then about as much as using the Mac with the lid open. Plug in when you can.

Does Lidless send any data anywhere?

No. No network access, no telemetry, no analytics, no account. It reads the local process list and runs pmset.

Which Macs and macOS versions?

macOS 13 Ventura and later, including Tahoe. Universal binary for Apple Silicon and Intel.
